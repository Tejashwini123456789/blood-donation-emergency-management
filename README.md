Blood Donation and Emergency Management System

Project Overview

The Blood Donation and Emergency Management System is a web-based application developed to simplify donor registration, blood group searching, and emergency blood requests.

The system helps manage donor information and emergency requirements efficiently. It also includes a Power BI dashboard to analyze donor availability and emergency requests.

Features

- Donor Registration
- Search Donors by Blood Group
- View Donor Details
- Update and Delete Donor Records
- Submit Emergency Blood Requests
- View Emergency Requests
- Admin Dashboard
- Power BI Data Visualization

Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Python, Flask
- Database: MySQL
- Data Visualization: Microsoft Power BI

Project Objective

To provide a centralized platform for managing blood donor details and emergency blood requirements while supporting data-driven analysis of donor availability.
